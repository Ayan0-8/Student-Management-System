# Student Management System

A simple command-line Student Management System built using Python. This project allows users to manage student records through a menu-driven interface.

## Features

- Add new student records
- View all student records
- Search students using roll numbers
- Update existing student details
- Delete student records
- Validate student names, ages, and roll numbers
- Store student data using JSON
- Handle invalid or corrupted database entries
- Handle file-related errors

## Technologies Used

- Python
- JSON
- File Handling
- Exception Handling

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Ayan0-8/Student-Management-System.git
   ```

2. Open the project folder:

   ```bash
   cd Student-Management-System
   ```

3. Run the program:

   ```bash
   python main.py
   ```
